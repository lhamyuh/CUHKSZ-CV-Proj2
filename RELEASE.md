# What is (and is not) in this repository

The repository keeps **source, configs, report and small evidence**. Everything generated or
heavy is published as a GitHub **Release** asset; the model weights stay there too, because the
course guide asks us to keep the final scene and object models until grading is complete.

## Note on the archive format

The zip is built by `tools_local/make_zip.py`, which writes forward-slash entry names
(`226010334_LinyuYANG/report.pdf`). `Compress-Archive` writes backslashes, which some Linux
unzip tools treat as literal characters, so do not rebuild it with PowerShell.
