4. Task C: placing the camera in Garden
Scene geometry. We fit the tabletop directly in the recon-
struction: points whose projection falls inside an image-
space ellipse around the table are selected in a validation
view, and RANSAC returns a plane with 8 409 inliers. Its
normal (within 4.1◦ of the average camera up vector over
six views) defines the scene up axis, its inlier centroid the
table centre, and the inlier spread a radius of 0.99 scene
units; the camera sits 0.78 units above the plane. The two
independent estimates agree, which fixes the metric scale to
roughly one unit per metre.

Scale and transform. The object’s pruned point cloud
has a PCA frame in which the body width, height and
depth measure 2.41, 1.95 and 1.40 units. An OM-2 body
is 136 mm wide, so the uniform scale is s = 0.0566
for the physical size (13.6 cm wide). At the shot dis-
tance that projects to only 71–95 px, which reads as a
toy, so the delivered placement uses s = 0.113 (27 cm
equivalent) with the camera 1.20 units from the table cen-
tre. The transform is a similarity: positions are mapped
by sRp + t, log-scales are offset by log s, and rotations
are left-multiplied by the quaternion of R; this is what
fusion/placement.json stores as a 4 × 4 matrix act-
ing on column vectors.

Grounding and contact. Two passes fix the contact.
First, the object is rotated so that its own base is parallel
to the table: RANSAC fits the largest planar cluster of the
object (which turns out to lie 46.9◦ away from the PCA-
aligned “up”), and that plane is mapped onto the table plane.
Second, the object is shifted along the table normal until its
base plane coincides with the fitted tabletop, which removes
the 47.7 mm gap of the first attempt. Because the underside
was never observed, the base is open, so we keep the object
20 mm into the surface and darken the table underneath with
